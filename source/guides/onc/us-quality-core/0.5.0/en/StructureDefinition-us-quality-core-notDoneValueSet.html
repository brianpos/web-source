Extension: USQualityCore Not Done ValueSet

Official URL: http://fhir.org/guides/onc/us-quality-core/StructureDefinition/us-quality-core-notDoneValueSet Version: 0.5.0
Draft as of 2026-06-05 Computable Name: USQualityCoreNotDoneValueSet

A logical reference (e.g. a reference to ValueSet.url) to a value set/version that identifies a set of possible coded values representing activities that were not requested, ordered, or performed.

Context of Use

    This extension may be used on the following element(s)

    • Element ID: CodeableConcept

Usage info

Usages:
